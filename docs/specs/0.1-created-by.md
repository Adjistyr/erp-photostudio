# 0.1 `created_by` di tabel transaksi

| Fase | Prioritas | Estimasi | Prasyarat | Keputusan |
|---|---|---|---|---|
| 0 — Fondasi jejak | P1 | S | — | K4 (dasar untuk peran) |

## Tujuan

Setiap catatan yang menyentuh uang atau operasional tahu **siapa yang mencatatnya**. Hari ini dua owner berbagi akses penuh dan tidak ada kolom pencatat; begitu admin ikut input (Fase 5), selisih kas tidak bisa ditelusuri tanpa ini.

## Lingkup

**Termasuk**
- Kolom `created_by` di 9 tabel transaksi + trait pengisi otomatis + relasi `creator`.
- Menampilkan nama pencatat di riwayat yang sudah ada di UI (Sheet detail order, aset, modal).

**Tidak termasuk**
- `updated_by` — prinsip "riwayat tidak diedit" (`docs/database.md`) membuat update jarang; perubahan order dicatat lewat 0.2.
- Filter/laporan per pencatat — baru berarti saat ada > 2 pengguna (5.1).
- Backfill data lama — tetap `null`, ditampilkan sebagai "tidak tercatat".

## Aturan bisnis

1. `created_by` diisi dari user yang sedang login saat baris **dibuat**; tidak pernah diubah setelahnya.
2. Baris yang dibuat tanpa sesi login (seeder, tinker, job) → `null`, bukan error.
3. Menghapus user **tidak** menghapus catatannya; `created_by` jadi `null` (`nullOnDelete`).
4. Pemanggil boleh menetapkan `created_by` eksplisit (mis. impor); trait hanya mengisi bila masih kosong (`??=`).

Kolom: `$table->foreignId('created_by')->nullable()->constrained('users')->nullOnDelete();` — tanpa index tambahan (FK PostgreSQL tidak membuat index otomatis, tapi tidak ada query per pencatat sampai 5.1). `down()` → `dropConstrainedForeignId('created_by')`.

Model: trait baru `Modules\Shared\Models\Concerns\RecordsCreator`

```php
trait RecordsCreator
{
    public static function bootRecordsCreator(): void
    {
        static::creating(function (Model $model): void {
            $model->created_by ??= auth()->id();
        });
    }

    /** @return BelongsTo<User, $this> */
    public function creator(): BelongsTo
    {
        return $this->belongsTo(User::class, 'created_by');
    }
}
```

Dipasang di: `Order`, `Payment`, `JobCost`, `OperatingExpense`, `Asset`, `AssetMaintenance`, `OwnerContribution`, `FundWithdrawal`, `Investment`. Tambah `created_by` ke `#[Fillable]` masing-masing dan `@property int|null $created_by` di docblock (PHPStan level 7).

Catatan desain: dipilih trait + `creating`, bukan mengisi di tiap controller — sembilan titik tulis, satu aturan; kalau ada jalur tulis baru (mis. impor), otomatis ikut.
