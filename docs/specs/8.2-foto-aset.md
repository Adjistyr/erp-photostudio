# 8.2 Foto alat & nota/garansi aset

| Fase | Prioritas | Estimasi | Prasyarat | Keputusan |
|---|---|---|---|---|
| 8 — Aset jadi register alat (11 Okt 2026) | P2 | M | 8.1 | User 11 Okt 2026: tahap 2 dari review modul Aset |

## Tujuan

Kondisi alat terdokumentasi (saat beli, saat rusak, sebelum dijual) dan nota/kartu garansi tidak perlu dicari saat klaim — keduanya menempel di halaman detail aset.

## Lingkup

**Termasuk**
- Dua galeri per aset: **Foto alat** (maks 8, foto pertama = sampul) dan **Nota & garansi** (maks 4).
- Unggah beberapa sekaligus, hapus, jadikan sampul (foto alat).
- Sampul tampil di daftar aset (sel nama) dan kepala halaman detail.

**Tidak termasuk**
- Foto per servis (bukti perbaikan) — bisa menyusul bila diminta.
- Penyimpanan cloud — disk `local` privat; pindah lewat konfigurasi saat hosting diputuskan.

## Aturan bisnis

1. **Privat.** File di disk `local` (`storage/app/private/assets/{aset}/`), dibuka lewat route ber-`auth` — bukan URL publik. Nota memuat harga & data pribadi; berbeda dengan foto katalog (7.1) yang memang untuk publik.
2. Foto alat: JPG/PNG/WebP. Nota & garansi: JPG/PNG/WebP **atau PDF** (nota marketplace umumnya PDF). Maks 2 MB per file; gambar ≤ 4000 × 4000.
3. Gambar disandikan ulang ke WebP (≤ 1600 px + thumbnail 400 × 400) seperti 7.1 — EXIF terbuang. PDF disimpan apa adanya, tanpa thumbnail (ikon dokumen).
4. Browser mengecilkan gambar sebelum unggah (batas PHP 2 MB); PDF dikirim apa adanya.
5. Melebihi batas jumlah per jenis → seluruh unggahan ditolak dengan sisa slot.
6. Hapus = baris + file, lewat konfirmasi. Foto aset dilepas tetap bisa dilihat & dihapus (riwayat).
7. Foto aset lain tidak bisa dibuka/dihapus lewat URL aset ini (404).

## Perubahan data

- `asset_photos`: `id`, `asset_id` FK cascade, `kind` (`item` | `receipt`), `path`, `thumb_path` nullable (PDF), `mime`, `original_name` (nama file asli, untuk PDF), `position`, `created_by`, timestamps.
- `Modules\Shared\Support\ImageEncoder` — pengolah GD dari `StoreCatalogPhoto` dipindah ke sini; katalog & aset memakainya.

## Backend

| Method | Path | Name |
|---|---|---|
| POST | `assets/{asset}/photos` | `assets.photos.store` |
| GET | `assets/{asset}/photos/{photo}` (`?size=thumb`) | `assets.photos.show` |
| DELETE | `assets/{asset}/photos/{photo}` | `assets.photos.destroy` |
| PATCH | `assets/{asset}/photos/{photo}/cover` | `assets.photos.cover` |

Semua `scopeBindings`. Props detail + `photos: {id, kind, url, thumb_url|null, is_pdf, name}[]`; daftar + `photo_url` (thumbnail sampul).

## Frontend

- `resizeForUpload` & `fitWithin` pindah ke `resources/js/lib/photo-resize.ts` (dipakai dua modul).
- `PhotoGallery` jadi generik (`components/photo-gallery.tsx`): URL unggah/hapus/sampul lewat props, `accept`, `max`, opsi PDF. Katalog memakainya tanpa perubahan perilaku.
- Halaman detail aset: bagian "Foto alat" dan "Nota & garansi". Daftar: thumbnail di sel nama.
