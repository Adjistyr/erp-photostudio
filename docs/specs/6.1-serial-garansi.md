# 6.1 Nomor seri + garansi aset

| Fase | Prioritas | Estimasi | Prasyarat | Keputusan |
|---|---|---|---|---|
| 6 — Aset & lainnya | P3 | S | — | — |

## Tujuan

Saat klaim garansi, servis resmi, atau asuransi, owner tidak perlu mencari nota pembelian: nomor seri dan batas garansi ada di baris aset.

## Lingkup

**Termasuk** — dua kolom baru, dua field di dialog Tambah Aset, tampil di Sheet detail, badge garansi.

**Tidak termasuk** — foto/scan nota (butuh storage, lihat 6.7); satu nomor seri per unit untuk aset `units > 1` (baterai × 2) — satu kolom teks bebas, pisahkan koma; pengingat garansi hampir habis (cukup badge).

## Aturan bisnis

1. Keduanya opsional; aset lama tetap valid tanpa isian.
2. `warranty_until` boleh di masa lalu (garansi sudah habis — tetap informasi).
3. Badge: `warranty_until` ≥ hari ini → "Garansi s/d 12 Mar 2027" hijau; < hari ini → "Garansi habis" abu-abu; null → tidak ada badge.
4. Kolom tidak bisa diubah setelah dibuat (belum ada edit aset di app) — ketik ulang lewat lepas + tambah **tidak** disarankan; ini alasan menambah `assets.update` terbatas (lihat Backend).

## Perubahan data

Migrasi `add_serial_and_warranty_to_assets`: `serial_number` string(100) nullable, `warranty_until` date nullable. `Asset`: `#[Fillable]` + docblock + cast `warranty_until => 'immutable_date'`.

## Backend

### Route
| Method | Path | Name | Handler |
|---|---|---|---|
| PATCH | `assets/{asset}/details` | `assets.details` | `AssetController@updateDetails` (baru) — hanya `model`, `serial_number`, `warranty_until`; **bukan** edit nilai/tanggal beli (itu mengubah modal) |

### Request
`StoreAssetRequest` + (baru) `UpdateAssetDetailsRequest`: `serial_number` nullable string max:100; `warranty_until` nullable `date_format:Y-m-d`. Attributes: "nomor seri", "garansi sampai".

### Controller
`updateDetails` → `$asset->update($request->validated())`, toast "Detail {nama} diperbarui". `index` props menambah `serial_number`, `warranty_until`, `warranty_active: bool|null`.

### Props Inertia
```ts
serial_number: string | null; warranty_until: string | null; warranty_active: boolean | null;
```

## Frontend

- Dialog Tambah Aset: dua field setelah "Merek / model" (grup "Identitas", collapsible agar form tidak memanjang).
- Sheet detail: baris "No. seri" (mono, tombol salin) dan badge garansi di header; tombol "Ubah detail" → dialog kecil (model, seri, garansi).
