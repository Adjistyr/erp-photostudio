# 7.5 Item produk di order studio/event

| Fase | Prioritas | Estimasi | Prasyarat | Keputusan |
|---|---|---|---|---|
| 7 — Permintaan tambahan (12 Okt 2026) | P2 | M | 7.3, 7.4 | User 12 Okt 2026: order tidak hanya item jasa — tambahkan produk |

## Tujuan

Sesi studio atau event sering disertai produk fisik (cetak tambahan, album, bingkai). Dulu Form Order hanya menerima paket jasa, jadi produk harus dicatat terpisah lewat POS atau sebagai item custom tanpa HPP.

## Aturan bisnis

1. Buat & Ubah Order menerima **produk aktif** di samping paket jasa (paket jasa tetap disaring per lini). Pilihan dikelompokkan "Paket jasa" / "Produk".
2. Baris produk menyimpan snapshot nama, harga, dan **HPP** dari katalog — HPP bahan masuk Laba Rugi seperti penjualan POS.
3. Produk bervarian wajib varian aktif miliknya (aturan sama dengan POS, satu helper `ResolvesCatalogLines::rejectWrongVariants`); nama baris "Produk – Varian", harga & HPP varian.
4. Ubah Order: varian hanya dicek untuk baris baru — baris lama tidak berganti isi.
5. Produk bervarian tanpa varian aktif tidak ditawarkan.
6. Omzet produk di order studio/event masuk lini order itu (studio/event), bukan retail; Laporan Produk terlaris tetap menghitung produknya.
