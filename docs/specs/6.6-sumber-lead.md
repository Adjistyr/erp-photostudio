# 6.6 Sumber lead per order

| Fase | Prioritas | Estimasi | Prasyarat | Keputusan |

## Tujuan

Kalau studio mulai beriklan, owner butuh "order bulan ini datang dari mana" per **order**, bukan per customer — customer lama bisa datang lagi lewat kanal berbeda. Hari ini `customers.source` ada tapi tidak sampai ke order dan laporan.

Bangun hanya ketika marketing mulai terstruktur (ada anggaran iklan yang mau diukur).

## Lingkup

**Termasuk** — kolom `orders.source`, default dari customer saat buat order, pilihan di form order, agregat di Laporan Penjualan.

**Tidak termasuk** — kampanye/UTM; biaya iklan per kanal (ROI) — biaya operasional sudah punya kategori "Marketing", cukup dibandingkan manual; sumber untuk retail (walk-in = "Lewat depan studio" tersirat, tidak dicatat).

## Aturan bisnis

1. Pilihan sumber = `Customer::SOURCES` (satu daftar, tidak ada duplikat definisi).
2. Saat buat order studio/event: `source` default = `customer.source`; admin boleh mengubah; boleh kosong.
3. Mengubah `source` order **tidak** mengubah `customers.source` (sumber pertama kali kenal tetap di customer).
4. Laporan Penjualan bulan terpilih: tabel "Sumber order" (sumber, jumlah order, omzet basis kas bulan itu, share) — order tanpa sumber dikelompokkan "Tidak dicatat".

## Perubahan data

Migrasi `add_source_to_orders`: `source` string nullable setelah `notes`. `Order`: fillable + docblock. Tidak ada backfill (order lama "Tidak dicatat").

## Backend

### Route
Tidak ada.

### Request
`StoreOrderRequest`/`UpdateOrderRequest`: `source` nullable `Rule::in(Customer::SOURCES)`; attributes "sumber order". POS tidak menerima `source`.

### Controller / Service
- `OrderController@store`: `source = $data['source'] ?? $customer->source`.
- `SalesReport` (Finance): metode baru `bySource(month): array<{source|null, orders, revenue, share}>` — omzet dihitung dari pembayaran bulan itu per order (konsisten dengan laporan lain), jumlah order = order dengan pembayaran di bulan itu.
- `ReportController@sales` props `by_source`.
- `orderProps()`: `source`.

### Props Inertia
```ts
source: string | null;                          // order
by_source: { source: string | null; orders: number; revenue: number; share: number }[];  // laporan
```

## Frontend

- `order-form.tsx`: `Select` "Sumber order" di bawah customer, terisi otomatis saat customer dipilih (ditandai teks kecil "dari data customer"), bisa diubah.
- Sheet detail: baris "Sumber" bila ada.
- `reports/sales.tsx`: bagian baru "Sumber order" dengan `Progress` share (pola sama bagian per lini di Laporan Piutang).
