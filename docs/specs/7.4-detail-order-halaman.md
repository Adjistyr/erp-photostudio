# 7.4 Detail order jadi halaman + edit yang mudah ditemukan

| Fase | Prioritas | Estimasi | Prasyarat | Keputusan |
|---|---|---|---|---|
| 7 — Permintaan tambahan (12 Okt 2026) | P2 | M | 1.2 | User 12 Okt 2026: detail order halaman baru, bukan sidebar; perlu edit data |

## Tujuan

Edit order sudah ada sejak 1.2, tapi tombolnya tersembunyi di dasar Sheet dan order retail tidak bisa diubah sama sekali. Detail order jadi halaman penuh dengan tombol Ubah di kepala halaman.

## Aturan bisnis

1. `GET orders/{order}` → halaman detail (isi sama dengan Sheet lama). Baris daftar membuka halaman ini; nomor order juga tautan.
2. Simpan order baru dan simpan perubahan → halaman detail order itu. Aksi status (lanjut/mundur), batal, link hasil → kembali ke halaman asal (`back()`).
3. **Retail bisa diubah**: customer & catatan saja. Retail selalu Diserahkan, jadi item & tanggal terkunci oleh aturan K1 yang sama dengan order Diserahkan. Customer opsional untuk retail (walk-in); studio/event tetap wajib.
4. Order batal tetap tidak bisa diubah (404 halaman edit, 422 simpan).
5. Baris order retail berisi produk: halaman edit mengirim nama produk baris lama (bukan hanya jasa); baris **baru** tetap harus jasa (spek 7.5 membuka produk).
