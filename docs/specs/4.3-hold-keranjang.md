# 4.3 Hold / parkir keranjang di POS

| Fase | Prioritas | Estimasi | Prasyarat | Keputusan |
|---|---|---|---|---|
| 4 — Kenyamanan transaksi | P3 | S | — | — |

## Tujuan

Customer A masih memilih, customer B mau bayar dulu: admin menahan keranjang A, melayani B, lalu memulihkan A — tanpa mencatat ulang.

## Lingkup

**Termasuk**
- Tahan keranjang (maks 5) ke `localStorage` browser, pulihkan, buang.

**Tidak termasuk**
- Penyimpanan di server / berbagi antar perangkat — satu kasir, satu browser. `// ponytail: localStorage; pindah ke server bila dua kasir berbagi antrean`.
- Keranjang tertahan muncul di laporan — belum jadi transaksi.
- Kedaluwarsa otomatis — admin membuang manual; daftar maksimal 5 membuat tumpukan terlihat.

## Aturan bisnis

1. Yang ditahan: `items` (`catalog_item_id`, `quantity`), `discount` (teks input + mode dari 4.1 bila ada), `customer_name` (+ `customer_phone` bila 2.1 ada), `method`, label, waktu ditahan.
2. Label default: `customer_name` bila terisi, kalau tidak "Keranjang HH:MM". Boleh diubah di dialog tahan.
3. Maks 5 keranjang; tombol Tahan nonaktif dengan tooltip "Maksimal 5 — buang salah satu dulu".
4. Memulihkan mengganti keranjang aktif. Bila keranjang aktif tidak kosong, konfirmasi "Keranjang sekarang ditahan dulu?" dengan dua pilihan: *Tahan lalu pulihkan* / *Buang lalu pulihkan*.
5. Saat dipulihkan, item yang **sudah tidak aktif/terhapus** di katalog (`products` props tidak memuatnya) dibuang dengan toast "2 item tidak lagi tersedia dan dilewati" — harga selalu dari katalog saat simpan, bukan dari yang ditahan.
6. Keranjang kosong tidak bisa ditahan.
7. Data rusak di `localStorage` (bukan JSON / bentuk tidak sesuai) → diabaikan dan ditimpa, bukan error.

## Perubahan data

Tidak ada (server). Klien: key `localStorage['pos.held']` berisi `HeldCart[]` versi 1:

```ts
interface HeldCart {
  v: 1;
  id: string;            // crypto.randomUUID()
  label: string;
  heldAt: string;        // ISO
  items: { catalog_item_id: number; quantity: number }[];
  discountInput: string;
  discountMode: 'rp' | 'pct';
  customer_name: string;
  customer_phone?: string;
  method: PaymentMethod;
}
```
