# 4.5 Ekspor CSV

| Fase | Prioritas | Estimasi | Prasyarat | Keputusan |
|---|---|---|---|---|
| 4 — Kenyamanan transaksi | P3 | S | 3.1 (`ListQuery`), 3.3 (`CashReceipts`) | — |

## Tujuan

Owner bisa menyerahkan data ke akuntan/pajak/asuransi atau mengolahnya di spreadsheet tanpa salin-tempel dari tabel.

## Lingkup

**Termasuk**
- Tiga ekspor: order (dengan filter yang sedang aktif), kas harian per bulan, daftar aset.
- Satu helper streaming tanpa paket tambahan.

**Tidak termasuk**
- Excel (`.xlsx`) — CSV dibuka Excel/Sheets; paket `maatwebsite/excel` tidak sepadan.
- Ekspor laporan Laba Rugi/Bagi Hasil — formatnya dokumen, bukan tabel; cetak dari browser sudah ada.
- Impor dari CSV.
- Penjadwalan/ekspor otomatis.

## Aturan bisnis

1. Hanya pengguna login (middleware grup yang sama). Setelah 5.1: ekspor order & kas = `view-finance` (memuat HPP/margin) — tandai di route sekarang dengan komentar.
2. Ekspor order mengikuti **filter yang sama** dengan daftar (`q`, `line`, `status`, `pay`, `from`, `to`) tanpa paginasi; maksimal 10.000 baris, lebih dari itu → 422 "Persempit rentang tanggal" (streaming tetap, batas untuk melindungi DB dari query tanpa filter).
3. Format: pemisah koma, kutip ganda via `fputcsv`, **BOM UTF-8** di awal agar Excel membaca "é"/"–" dengan benar, baris baru `\n`. Tanggal `Y-m-d`, uang **integer rupiah** tanpa pemisah ribuan, persen desimal (0.35), enum nilai mentah **dan** label (dua kolom) supaya terbaca orang maupun mesin.
4. Nama file `potrait-time-<jenis>-<YYYY-MM-DD atau YYYY-MM>.csv`.
5. Satu baris = satu order (bukan per item) di ekspor order; item diringkas (`itemsSummary()`), supaya total per baris = total order dan bisa dijumlahkan langsung.

### Controller / Action / Service
`Modules\Shared\Http\CsvResponse` (baru — namespace `Modules\Shared\Http` belum ada; buat folder):

```php
final class CsvResponse
{
    /**
     * @param iterable<array<int, scalar|null>> $rows
     * @param list<string> $header
     */
    public static function stream(string $filename, iterable $rows, array $header): StreamedResponse
    {
        return response()->streamDownload(function () use ($rows, $header): void {
            $out = fopen('php://output', 'w');
            fwrite($out, "\xEF\xBB\xBF");          // BOM — Excel Windows
            fputcsv($out, $header);
            foreach ($rows as $row) { fputcsv($out, $row); }
            fclose($out);
        }, $filename, ['Content-Type' => 'text/csv; charset=UTF-8']);
    }
}
```

`$rows` diberi sebagai generator (`yield`) dari `->lazy()`/`cursor()` supaya 10.000 baris tidak dimuat ke memori.

Kolom:
- **Order**: `nomor, tanggal_layanan, jam, lini, lini_label, customer, hp, item, total, dibayar, dikembalikan (bila 4.2), sisa, status_bayar, status_bayar_label, status_kerja, status_kerja_label, hpp_bahan, biaya_job, margin, lokasi, catatan, dicatat_oleh (0.1), dibuat_pada`.
- **Kas harian** (dari `CashReceipts::forMonth`, per hari × metode, baris tipe `masuk`/`keluar`): `tanggal, metode, metode_label, jenis, jumlah, jumlah_transaksi`, lalu baris total per metode di akhir dengan `tanggal = 'TOTAL'`.
- **Aset**: `kode, nama, kategori, model, unit, harga_unit, nilai_beli, tanggal_beli, umur_bulan, nilai_buku, persen_maintenance, interval_bulan, servis_terakhir, servis_berikutnya, status, status_label, dilepas_pada, alasan_lepas, harga_jual, nomor_seri (bila 6.1)`. Nilai buku dari perhitungan yang sudah dipakai di props `AssetController@index` — ekstrak ke metode model bila masih inline.
