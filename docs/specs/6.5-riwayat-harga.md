# 6.5 Riwayat harga katalog

| Fase | Prioritas | Estimasi | Prasyarat | Keputusan |

## Tujuan

Owner bisa menjawab "sejak kapan harga cetak 4R naik, dan berapa sebelumnya?" tanpa membuka order lama satu per satu. Order lama sudah aman (snapshot) — ini murni analisis.

## Lingkup

**Termasuk** — tabel riwayat yang diisi otomatis saat harga/HPP berubah, tab "Riwayat" di dialog Ubah katalog.

**Tidak termasuk** — penjadwalan harga (berlaku mulai tanggal X); riwayat nama/kategori; grafik.

## Aturan bisnis

1. Satu baris riwayat setiap kali `price` **atau** `unit_cost` berubah saat `update`; perubahan field lain tidak mencatat.
2. Baris pertama dibuat saat item dibuat (harga awal), supaya riwayat selalu punya titik awal.
3. Riwayat tidak bisa dihapus/diedit; menghapus item katalog tidak ada di app (hanya nonaktif), jadi FK `cascadeOnDelete` aman.
4. Menampilkan "Berlaku 12 Agu 2026 – 6 Okt 2026" dihitung dari baris berikutnya; baris terakhir "Berlaku sejak …".

## Perubahan data

Tabel (baru) `catalog_price_changes`: `id`, `catalog_item_id` FK cascadeOnDelete, `price` bigint, `unit_cost` bigint nullable, `changed_by` FK users nullable nullOnDelete, `created_at` (tanpa `updated_at`). Index (`catalog_item_id`, `created_at`).

Model `CatalogPriceChange` (baru) tanpa timestamps otomatis (`UPDATED_AT = null`). `CatalogItem`: relasi `priceChanges()`; observer di model (`created`, `updated` dengan `wasChanged(['price','unit_cost'])`) membuat baris — di model, bukan controller, supaya seeder/impor ikut tercatat.

## Backend

### Route / Request
Tidak ada.

### Controller
`CatalogItemController@index`: `items[].price_changes: [{price, unit_cost, changed_by_name, at}]` urut terbaru, dibatasi 20 terakhir per item (`// ponytail: 20 cukup; paginasi bila item punya > 20 perubahan`). Eager-load `priceChanges.creator` (relasi `creator` meniru pola 0.1 dengan kolom `changed_by`).

### Props Inertia
```ts
price_changes: { price: number; unit_cost: number | null; changed_by_name: string | null; at: string }[];
```

## Frontend

- Dialog Ubah katalog: `Tabs` "Data | Riwayat harga". Tab Riwayat: tabel kecil (Berlaku, Harga, HPP, Oleh) dengan selisih vs baris sebelumnya ("+Rp 2.000") hijau/merah. Satu baris saja → kalimat "Harga belum pernah berubah sejak {tanggal}".
- Untuk admin (5.1) kolom HPP disembunyikan mengikuti ada-tidaknya `unit_cost` di props (server menghapus `unit_cost` dari riwayat juga).
