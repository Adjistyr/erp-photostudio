## Tujuan

Template "Reminder H-1" sudah ada di Komunikasi, tapi untuk memakainya admin harus: buka Kalender → cari sesi besok → buka Customer → salin HP → buka Komunikasi → salin teks → WhatsApp. Dashboard sudah punya "Jadwal hari ini" (`bookings_today`); yang kurang persis satu blok di bawahnya: **besok**, dengan tombol WA yang pesannya sudah terisi.

## Lingkup

**Termasuk**
- Prop `bookings_tomorrow` di `DashboardController` + blok "Jadwal besok" di `dashboard.tsx`.
- Tombol WA per baris dengan pesan dari template `reminder` yang dipersonalisasi di klien.
- Placeholder baru di template reminder: `{tanggal}`, `{jam}`, `{lokasi}`.

**Tidak termasuk**
- Pengiriman otomatis (keputusan: WA manual, analisis bagian 7).
- Penanda "sudah diingatkan" per order — menambah state yang harus di-reset; owner melihat dari riwayat chat. Kalau terbukti perlu, jadi `order_events` tipe `reminded` (0.2) — catat sebagai kandidat, bukan dibangun.
- Reminder untuk lusa / minggu ini — Kalender sudah menjawab itu.

## Aturan bisnis

1. "Besok" = `today()->addDay()` menurut zona waktu app (`config('app.timezone')`), sama dengan `bookings_today`.
2. Baris = order **studio & event** dengan `service_date = besok`, `work_status != cancelled`, urut `service_time` (null terakhir) — query identik dengan `bookings_today` kecuali tanggal; satu method privat `scheduledOn(CarbonInterface $date)` untuk keduanya.
3. Pesan WA = `personalise(reminder_template, row)` dengan: `{nama}` → nama depan customer, `{tanggal}` → `formatTanggal(service_date)`, `{jam}` → `service_time` atau "sesuai kesepakatan" bila null, `{lokasi}` → `location` atau "studio" bila null, `{link}` → "" (tidak relevan di reminder).
4. Tanpa nomor HP → tombol **disabled** dengan tooltip "Belum ada nomor HP — lengkapi di Customer", bukan disembunyikan (admin harus tahu kenapa tidak bisa).
5. Template dibaca lewat `MessageTemplate::resolved()` (override di tabel menang atas default) — perubahan owner di Komunikasi langsung berlaku.
6. Default template `reminder` diperbarui memakai placeholder baru: "Halo {nama}, mengingatkan sesi foto {tanggal} jam {jam} di {lokasi}. Datang 10 menit lebih awal ya supaya persiapannya santai. Kalau ada perubahan jadwal, balas pesan ini." Override yang sudah disimpan owner **tidak** disentuh (placeholder yang tidak ada di teksnya dibiarkan saja).
